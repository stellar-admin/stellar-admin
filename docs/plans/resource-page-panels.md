# Panels on resource pages

Status: proposed (2026-10-26).

Let developers add their own panels to a resource's index page, forms and view page. Examples are a chart, a chat widget, or other information rendered from a partial view or loaded from an MVC action or Razor Page.

Related: row details already support panels on the index page (`EnableRowDetails`), and [configured-row-details](configured-row-details.md) proposes more. Also see [home-page-panels](home-page-panels.md), since the two could share a panel API.
