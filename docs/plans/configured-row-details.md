# Configured row details

Status: proposed (2026-10-13).

Row-detail panels on the admin panel resource index are hand-written partials (`EnableRowDetails` with a partial name). Let a panel be configured from display fields instead, the way the view page (`AllowView`) configures its fields, so simple panels need no partial.

Context: decision 5 of the archived [info-lists](archive/info-lists.md) plan, and the archived [dashboard-row-details](archive/dashboard-row-details.md) plan. Research, design and implement as appropriate.
