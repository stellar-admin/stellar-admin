# Panels on the home page

Status: proposed (2026-10-26).

Let developers add panels or other elements to the admin panel's home page, such as stats, charts or links, without replacing the whole page.

Today the home page displays the setup checklist in Development and links to the resources otherwise (`ConfigureHomePage()`). The only way to change it is to override `Areas/StellarAdmin/Views/Home/Index.cshtml`, whose model is internal.
