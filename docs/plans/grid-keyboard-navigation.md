# Keyboard navigation in the grid

Status: proposed (2026-10-18).

Make the index grid faster to use without a mouse, such as moving between rows, opening or editing a row, adding a record and focusing the search. From the Voyager Travel session feedback.

Read the current grid and its keyboard handling first, then propose the keys and behaviour to Jerrie before implementing.

Also settle how shortcuts are shown, for the grid's keys and the form buttons' existing Ctrl/Cmd+Enter (save) and Ctrl/Cmd+Shift+Enter (save and add another), which today only carry `aria-keyshortcuts`. Options explored in `sandbox/html/form-button-shortcuts.html` (2026-10-20): keys inside the buttons, tooltips, a footer hint line or legend, captions, reveal while the modifier is held or the form has focus, and a keyboard help button.
