Page subtitles

A line under the title of the view, edit and create pages. Each frame scrolls: scroll one to see the sticky header pass over the content.

The first section compares styles for the line itself. The Style picker in the control bar (bottom right) then applies one of them to every frame in the sections below it.

1. Styles for a per-record line

The view page of a product, with UseSubtitle(p => …) giving its sku and category. A is today's <sa-page-header-description> unchanged; the others add markup or a slot.

2. Across the pages

The chosen style on each page of the resource. Which pages show a line, and whether the create page (no record yet) gets fixed text or nothing, is open.

3. Fixed text, per-record, or both

The edit page with the two shapes from the plan: a fixed text per page (edit.Subtitle = "…"), the per-record line, and both together.

4. Other resources and edge cases

Bookings and customers, a long title, a long line, and the line folding away once the header is stuck (scroll the last frame).
