Checklist scenarios

Ten ways an application might use a checklist, each with the Razor that would build it, to find which checklist tag helpers every scenario needs and where a developer reaches for a component the library already has. The candidate: sa-checklist; sa-checklist-item and sa-checklist-item-link with status (Todo, InProgress, Done), title and description attributes; and the child parts sa-checklist-item-title, sa-checklist-item-description, sa-checklist-item-status (any content, for statuses beyond the three) and sa-checklist-item-actions. Giving an attribute and its own child part together throws. divider on the list draws rules from the text column (default), full width or not at all; muted on the title mutes it. There is no details part: anything else inside an item (a collapsible, a nested checklist) lays out below the text.
