Rich text editor

ProseKit (MIT, built on ProseMirror) as the editor, with a toolbar built only from StellarAdmin components: ghost buttons, toggles, a dropdown menu with a radio group, a popover with an input, and separators. Select text for the bubble menu. Paste, drop or pick an image to "upload" it; the upload is simulated (progress, then a data URL) where the real one would post to the ImageEditor upload endpoint. Drag the dot on a selected image to resize it. Hover a toolbar button for its tooltip and shortcut. Type / at the start of a line (or after a space) for the slash menu. In a table, hover a row or column for its grip: click it for the row or column menu, or drag it to reorder. Tab moves to the next cell and adds a row at the end; drag a column border to resize.
