Inline multiselect patterns

Patterns that live directly in the form: no popover, no sheet. They work best when the options fit on screen, when each choice needs extra data, or when the selection is really a two-dimensional set. Every demo is a real <form>; the box under it shows what the form would post. The last section covers read-only displays for index grids and detail views, which every multiselect editor needs regardless of how values are picked.
