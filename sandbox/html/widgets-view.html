Configuration problems

The admin panel kept running and worked around these. Fix them before you deploy.

Resources/Excursions/ ExcursionResourceRegistration.cs

1 4 1
31 // Computed without a title: left out 32 columns.Add(excursion => excursion.Price * 1.2m);

Warning: This column isn't shown because it's computed, so it has no property name to use as its title.

Give the column a Title.

33 });
⋯
35 // Price isn't sortable: ignored 36 index.DefaultSortBy(excursion => excursion.Price);

Warning: The list isn't sorted by Price because its column isn't sortable. It uses the data source's order instead.

Make the Price column sortable, or sort by another column.

Info: The page size 15 isn't one of the PageSizes, so the list adds it to them.

Warning: Excursions can't be created because ExcursionDataSource can't create them. There's no New button, and the create page returns 404.

Implement IResourceCreateHandler on ExcursionDataSource.

53 // /stellaradmin/excursion-bookings 54 admin.AddEfCoreResource<ExcursionBooking>();

Error: Excursion bookings is hidden, and its pages return 404, because no registered DbContext maps ExcursionBooking.

Add a DbSet<ExcursionBooking> to a DbContext registered with AddDbContext.

55 56 // A blank page name: the link is left out 57 admin.AddSidebarLink("Excursion report", SidebarLinkTarget.Page(" "));

Warning: Excursion report isn't in the sidebar because its page name is blank.

Pass the name of a Razor page to SidebarLinkTarget.Page.
