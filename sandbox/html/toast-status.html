Toast status treatments

How success, info, warning and error toasts show their type. A is what ships: every toast is the same neutral card and only the 16px icon is coloured, so a warning or an error reads like any other toast. B to F are candidates. Default and loading toasts stay neutral in every option. Each option shows light and dark side by side; the live toaster at the top uses the option picked in the control bar.
