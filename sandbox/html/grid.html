Grid (sa-grid / sa-grid-item)

One responsive grid for forms, sharing its attributes, tiers (base, sm 30rem, md 40rem, lg 56rem) and CSS with sa-details. Fields carry their own column-span*; anything else spans through sa-grid-item. Inside either grid a responsive field switches orientation at the width of its own column (decision 16). Markup below is what the tag helpers would emit; the inline --sa-cols*/--sa-span* values are resolved as ResponsiveGrid does (inherit upward, cap to each tier's columns, omit 1).

A · Live candidate: a booking's edit page

Drag the frame's bottom-right corner to resize it. The badge shows the tier the grid is in. Inputs, an explicit field, display fields and two grid items holding stacked sections; the Payment section's responsive display fields go side by side when their own column is wide enough, not when the grid is.

A′ · The same page at the plan's widths

420px lands in base (one column), 560px in sm (two), 720px in md (three), 1000px in lg (three; the audit item spans two). Frame widths include 20px padding each side.

B · Responsive fields measure their own column (16)

B1 is today: responsive display fields in a three-column sa-details switch at 32rem of the whole list, so each 290px column puts a label beside its value. B2 is the candidate: each display field is its own container, so they stay stacked until a column is wide enough. B3/B4 show the same for inputs: in a two-column sa-form-row the responsive fields measure the field group around the row; in sa-grid they measure their item.

C · Where a responsive display field switches

Inputs switch at 28rem of their column (field.css, unchanged). C1 uses the same 28rem for display fields (the candidate); C2 and C3 switch earlier, since a display field's value is text rather than a control. Each strip shows a two-column sa-details at 560px, 720px and 1000px, so columns are about 250, 330 and 470px.

D · Spans per tier

Each box prints its own attributes. columns-base="1" columns-sm="2" columns-md="4" columns-lg="6". full spans every column at that tier and later tiers inherit it; a number larger than a tier's columns is capped.

E · Display fields among inputs

A display field directly in sa-grid keeps the among-inputs style (input label, control height) and lines up with the inputs in its row; horizontal and responsive orientations follow its own width as in B2.
