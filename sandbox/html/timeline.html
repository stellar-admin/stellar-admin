Timeline scenarios

Eleven ways an application might use a timeline, each with the Razor that would build it, to find which timeline tag helpers every scenario needs and where a developer reaches for a component the library already has. A timeline is a list of events, with no status: progress you act on is the checklist's job. The candidate: sa-timeline (an ol, with size, time-placement, marker, and media-style); sa-timeline-item with title, description and time attributes, rail (the rail leaving it: solid, dashed or none) and current (progress: it and the items before it take the accent); and the child parts sa-timeline-item-title (with muted), -description, -time (a <time> with datetime), -media (an icon or avatar in the marker, with an optional label for screen readers when the icon means something) and -actions. Giving an attribute and its own child part together throws. Anything else inside an item (a collapsible, a comment, a card) lays out below the text. An item with no media shows the list's marker: a dot, a ring or its number.
