Rows that cannot expand

How an index shows rows whose details are not available, for a future ExpandWhen. Each grid is the AdminPlayground Products index; products under 10.00 (IDs 7, 27 and 1 here) cannot expand. Try the toggles, the expand-all toggle in the header, keyboard Tab, and row click (control bar).

1 — No indicator 2 — Disabled chevron 3 — Disabled chevron with a reason 4 — Muted placeholder 5 — Expands to an empty state

1 — No indicator

Rows that cannot expand have an empty toggle cell, so the columns still line up. Row click ignores them, and expand-all skips them. Screen readers hear nothing for them.

3 — Disabled chevron with a reason

The toggle stays, marked aria-disabled instead of disabled so it keeps focus and can show a tooltip with the reason, on hover and on keyboard focus. Screen readers announce it as a dimmed button named “No details for …”. API sketch: details.ExpandWhen(product => product.Price >= 10, reason: "No pricing details for products under 10.00").
