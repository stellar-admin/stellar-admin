Form button shortcuts

Ways to show Ctrl/⌘ + Enter (save) and Ctrl/⌘ + Shift + Enter (save and add another) on the create and edit page buttons. Each option shows the create page footer (with save and add another) and the edit page footer. Hover the buttons for the tooltip options; hold Ctrl or ⌘ (and Shift) for 7 and 8. Every option hides the keys on touch screens (the Device control), and the keys are aria-hidden since the buttons already carry aria-keyshortcuts.
