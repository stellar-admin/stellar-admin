Row detail panels as an accordion

The AdminPlayground Products index with three row detail panels (Pricing, Overview, Related). The first row is open in each grid. D1–D5 build on D; the earlier ideas are at the bottom. Use the control bar for themes, dark mode and which accordion items start open.
