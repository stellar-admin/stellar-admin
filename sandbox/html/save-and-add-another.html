Save and add another

Adding several records in a row, on the create page and with inline create, as decided on 2026-10-20. Both frames are live: type, save, and use the toggles above each to switch the feature and its carry-over. Saves are simulated; the address line shows where the real page would be. The Name field is required, so an empty save shows the error path.

Proposed API

Off by default. EnableAddAnother on the create builder turns it on for the create page and, with UseInlineRow(), the inline row. The optional builder names the fields whose saved values carry over to the next record. 

resource.AllowCreate(create =>
{
    create.Fields(fields => { /* ... */ });
    create.EnableAddAnother(another =>
    {
        another.KeepForNext(tour => tour.DestinationId);   // one call per field
        another.KeepForNext(tour => tour.Days);
        // another.Label = "Save and add another";          // default; also on ResourceCreateLabelsBuilder
    });
});

create.EnableAddAnother();                                 // no carry-over; returns the add-another builder

Create page: the button posts after=add-another; a successful save queues the usual "added" toast and redirects back to Create (Post/Redirect/Get) with a fresh model from the factory plus the kept values, carried in TempData. Inline: the row posts with ?another=true and the response is the saved row plus a new open row with the kept values; AfterSave applies once, when the run ends. KeepForNext must name an editable create field. The lookup create sheet is unchanged.

Shortcuts everywhere (create and edit pages, inline create and edit rows): Ctrl/⌘+Enter saves, Ctrl/⌘+Shift+Enter saves and adds another. Both modifiers work on every platform. Plain Enter still saves an inline row.

A — Create page

The create page as _FormPage renders it. Saving normally goes to the index; adding another comes back to an empty form with focus in the first field.

  • Button: a second submit button, "Save and add another", before the primary one. The "added" toast confirms each save.
  • Keyboard: Ctrl/⌘+Enter saves, Ctrl/⌘+Shift+Enter saves and adds another.

B — Inline create

The Tours index with UseInlineRow(), as _IndexDataGrid renders it. Rows added in a run stay where they were added (marked at the left edge) and aren't dimmed; the rest of the grid stays dimmed until you stop.

  • Button: a third row action, "Save and add another", between Save and Cancel. Enter and Ctrl/⌘+Enter save and close, as today.
  • A row under the open row counts the rows added. Save, Cancel or Esc ends the run: with ReloadGrid, the grid reloads (re-sorted) then; with KeepInPlace, the added rows stay put.
